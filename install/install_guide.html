Installation — Schritt für Schritt

1

DLLs installieren

Erstelle ein Verzeichnis, z.B. C:\Scripts\SAP_ODBC\ und kopiere folgende 5 DLLs dorthin:

  • sapodbcabap.dll — aus diesem Release
  • sapnwrfc.dll — aus dem SAP NWRFC SDK 7.50
  • icudt57.dll — aus dem SAP NWRFC SDK 7.50
  • icuin57.dll — aus dem SAP NWRFC SDK 7.50
  • icuuc57.dll — aus dem SAP NWRFC SDK 7.50
Die SAP-DLLs befinden sich im NWRFC SDK Verzeichnis unter nwrfcsdk\bin\. Falls das SDK noch nicht installiert ist, kann es von SAP heruntergeladen werden (SAP Note 2573790). Alle 5 DLLs müssen im selben Verzeichnis liegen.
Der Treiber ist mit MinGW kompiliert und die C++-Runtime ist statisch gelinkt — es werden keine zusätzlichen Runtime-DLLs (wie libgcc_s_seh-1.dll oder libstdc++-6.dll) benötigt.
2

Treiber und Datenquelle automatisch registrieren

Öffne PowerShell als Administrator und führe das mitgelieferte Skript aus:

.\install_driver.ps1

Das Skript:

  • prüft, dass alle 5 DLLs vorhanden sind
  • fragt interaktiv die Verbindungsparameter ab (User und Passwort sind Pflicht)
  • registriert den ODBC-Treiber in der Windows-Registry
  • legt eine System-DSN mit allen Verbindungsoptionen an

Alternativ können Parameter direkt übergeben werden:

.\install_driver.ps1 -DSNName "SAP_DAA" -SapHost "jbklsapas1daa.jbdmn.de"
Das Skript muss als Administrator ausgeführt werden. Rechtsklick auf PowerShell → „Als Administrator ausführen".
3

Weitere Systeme anlegen

Für jedes weitere SAP-System eine eigene DSN anlegen — der Treiber wird nur einmal registriert:

.\install_driver.ps1 -DSNName "SAP_KAA" -SapHost "jbklsapas1kaa.jbdmn.de"
.\install_driver.ps1 -DSNName "SAP_PAA" -SapHost "jbklsapas1paa.jbdmn.de"
Client (100), SysNr (10) und Lang (DE) sind vorbelegt. User und Passwort werden immer abgefragt.
4

Verbindung testen

In QlikView:

  1. Script-Editor öffnen (Strg+E)
  2. ODBC-Verbindung anlegen: ODBC CONNECT TO SAP_DAA;
  3. SQL eingeben: SQL SELECT * FROM MARA LIMIT 100;
  4. Daten werden geladen — Datumswerte kommen im Format YYYY-MM-DD

In QlikSense:

  1. Daten-Verbindung → ODBC → DSN „SAP_DAA" auswählen
  2. SQL eingeben oder Tabellen aus dem Katalog wählen
  3. SELECT * FROM MARA LIMIT 100

ODBC-Verbindungsstring (für SQLDriverConnect):

DSN=SAP_DAA;Host=jbklsapas1daa.jbdmn.de;SysNr=10;Client=100;User=DEIN_USER;Password=********;Lang=DE

Nutzung

Einfache Table-Reads

SELECT * FROM MARA LIMIT 100
SELECT MATNR, MTART, ERSDA FROM MARA WHERE MTART = 'FERT' ORDER BY MATNR

Der Treiber erkennt automatisch einfache Table-Reads und nutzt Paging (Chunking) für große Datenmengen — unbegrenzte Zeilenzahl.

Komplexe Queries (JOIN, Aggregation)

SELECT M.MATNR, M.MTART, T.MAKTX
FROM MARA M INNER JOIN MAKT T ON M.MATNR = T.MATNR
WHERE T.SPRAS = 'D'

Tabellen-Discovery

Der Treiber unterstützt SQLTables() und SQLColumns() — Tabellen und Spalten werden automatisch angezeigt, wenn die Anwendung diese ODBC-Funktionen nutzt (z.B. QlikView Katalog).

Datumsformate

Datumswerte kommen im ODBC-Standardformat YYYY-MM-DD, Zeitwerte als HH:MM:SS. In QlikView mit der Date#()-Funktion interpretieren:

Date#(ERSDA, 'YYYY-MM-DD') as ERSDA

Debug-Logging

Der Treiber unterstützt optionales Debug-Logging über den Registry-Wert LogEnable:

HKLM\SOFTWARE\ODBC\ODBC.INI\
    LogEnable = 1   (0 = aus, Default; 1 = an)

Bei aktiviertem Logging schreibt der Treiber Debug-Informationen nach C:\Temp\sap_odbc_debug.log.

LogEnable wird beim Verbindungsaufbau gelesen und muss manuell in der Registry gesetzt werden. Das Installations-Skript setzt den Wert nicht.

Einschränkungen

  • Read-only — keine INSERT/UPDATE/DELETE-Statements
  • Keine Parameter-Bindings — SQL als direkter String
  • Excel — aktuell nicht kompatibel, QlikView/QlikSense funktionieren
